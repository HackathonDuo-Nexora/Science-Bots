# Science Bots

Autonomous AI Research Team for AgentForge 2026.

**Track:** The Research Team

---

## Overview

The system uses multiple specialized AI agents:

- **Orchestrator** — Routes tasks and coordinates the agent pipeline
- **Researcher** — Gathers data from scientific sources and the web
- **Analyzer** — Processes and interprets research findings
- **Writer** — Drafts structured scientific content
- **Reviewer** — Validates accuracy and quality of outputs
